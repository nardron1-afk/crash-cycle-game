# Crash Cycle

Original mobile-friendly ragdoll bike physics game. Single self-contained `index.html` (canvas + vanilla JS, no assets).

**Play:** https://nardron1-afk.github.io/crash-cycle-game/

## Controls
- **Mobile:** Lean ◀/▶, GAS, BRAKE (on-screen). Pause / mute in the top-right.
- **Keyboard:** A/D or ←/→ lean, W/↑/Space gas, S/↓ brake, P pause, M mute, Esc menu.

## Levels
1. Training Hill — learn gas & lean  
2. Ramp Run — jumps + spikes  
3. Saw Alley — spinning saws  
4. Gap Jumper — big gaps  
5. Moving Mayhem — moving platforms  
6. Summit Sprint — final gauntlet  

Clear the flag to finish. Collect stars. Best times & star counts save in localStorage.

## Notes
100% original title, art, and design. Inspired only by the *feel* of ragdoll bike crash games — no third-party trademarks or assets.
